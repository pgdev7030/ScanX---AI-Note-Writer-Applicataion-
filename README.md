# ScanX | AI Note Writer Applicataion 
 
## ScanX

ScanX is an AI note taking app built to solve a simple problem: people collect notes and documents faster than they can organize or make sense of them. Instead of leaving users to manually sort through pages of text, ScanX reads the content and turns it into clear, usable output.

### Tech Stack
- **Next.js (App Router)** - keeps routing, layouts, and data fetching clean and fast as the app grows, so new features don't turn the codebase into a mess
- **React + Tailwind CSS** - responsive, simple interface
- **Convex DB** - real-time data sync without hand-rolling backend plumbing

### Features
- **Smart summarization** - long documents or notes get boiled down to what actually matters
- **Context-aware suggestions** - understands what a user is working on and offers relevant follow-ups instead of generic ones
- **PDF integration** - pull documents straight into the app and get them summarized or organized without extra steps

### Why it matters
ScanX solves the problem of information overload for anyone dealing with a lot of notes or documents: students, researchers, professionals. It saves time, cuts manual sorting, and turns raw content into something actually useful.
